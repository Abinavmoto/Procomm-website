# Procomm Dynamics website

Static marketing site for **Procomm Dynamics** / **FlexiFlow** / **FlexiConnect**.

## Local preview

Open `index.html` in a browser, or from the repo root:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/`.
